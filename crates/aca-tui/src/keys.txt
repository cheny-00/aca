aca 界面按键说明 —— 在界面里每一页按 ? 都能看到这一页的键,这里是每个键的详细说明。
打开会话后,按 Ctrl+Q(或 tmux 前缀键 + d)返回界面,会话继续运行。
Ctrl+Q 由 aca 绑定在 tmux 上,只在 aca 的会话中生效(包括其中另开的窗口 / 窗格);在普通 tmux 会话中,这个键照常发给里面的程序,
请用前缀键 + d 返回。如果你已经给 Ctrl+Q 绑定了别的操作,aca 不会覆盖。
打开页面、弹窗的那个键,再按一次就关闭(同 Esc)。

移动与选择
  ↑↓ j k    上下移动 · g / G 到顶部、底部 · J / K 下一个、上一个分组 · 输入数字直接跳转(1 再 2 = 12 号)·
            点一下选中,再点一下打开
  滚轮      在列表上切换会话;在预览上向上翻看输出,翻到顶后按 z 全屏阅读
  h l ← →   向外 / 向里一层。h:从窗口、子代理、子会话回到所属的会话;已经在最外一层(会话、分组标题)时,光标到左栏,
            停在列表现在所在的那一行(全部,或正在看的分组)。屏幕不到 130 列时平时没有左栏,h 把它叫出来盖在左边。
            l:在分组标题上进入这个分组(列表只列它的会话,⏎ 也一样)。
            会话派出了子代理(标题后面有 +N,或预览顶部有显示)时:l 把子代理展开成行,再按 l 进入第一个;
            h 在已展开的会话上先收起子代理。没有子代理的会话上按 l 无效。
  左栏      屏幕 130 列以上时在最左边:全部、置顶、每个分组(下级分组缩进)、回收站,每行右边是切过去会列出的会话数
            (按当前这一档、选了状态时按这种状态算),和其中 ◆ ◐ ✕ ● 各几个。
            光标在左栏时:↑↓ j k 换一处(列表马上跟着换,右边是这个分组的目录和置顶的笔记),g / G 到头尾,
            ⏎ / l / → 进入:光标回到列表,停在上次离开这一处时的那一行;停在回收站上按 ⏎ 打开回收站。
            分组那一行上,N、r、d、e、t、Q、⇧↑ ⇧↓ 和在分组标题上一样,Tab 把中间换成这个分组的另一页,
            o、s 是打开、回它的 router(见下面「分组的 router」);「全部」那一行上这两个键是打开、回总台;
            只对会话有用的键在左栏不起作用。点一下停过去,再点一下进入。
            在一个分组里按 Esc 也是到左栏。
            设置了随手问目录(^S 里的 s,config.toml 的 [scratch] dir)时:在那个目录工作的分组(没有就新建一个,叫「随手问」)
            排在「全部」下面、置顶前面,列表里也排在最前;光标不在哪个分组的会话上(左栏的「全部」那一行、普通 tmux 会话、
            空列表)时,N / n 新建的会话进这个分组、目录预填它的目录。这个分组可以改名,不能删除。
            它的名字前面有 ⌂;它下面的分组,名字里它那一段写成 ⌂(fun/manga 写成 ⌂/manga)。输入分组名和命令行里还是原来的路径。
            不到 130 列的屏幕:h(或点顶栏左边的标签)叫出左栏,盖在左边(手机上占满);⏎ / l 进入并收起,
            h / Esc 收起并回到叫出来之前看的那一处。这时在分组里按 Esc 是回到全部分组
  Tab       在一个分组里:换到它的下一页,任务 / 会话 / 笔记轮着走(顶上一排写着三页各有几条,任务写的是没完成的张数,
            正在看的那一页带下划线);再进这个分组时停在上次看的那一页,有没完成的任务单时先到任务页。
            全部分组只有一页,Tab 不起作用。
            任务页:一张任务单两行(状态、名字、#单号、多久前;下一行是眼下最要紧的一句:做它的会话在问什么、单子上的那一行字、
            交的时候说的话、完成时说的结果)。✓ 完成  · 待办,在做的是做它的会话自己的记号。完成的在前,其余按单号;
            右边是光标所在那一张:完成标准、谁交给谁、说了什么,下面是做它的会话。↑↓ j k、数字、g / G 选择;
            ⏎ 打开做它的会话,s 回它 / 回答它问的;n 新任务(先名字,再完成标准),e 修改;m 交给这个分组里的一个会话
            (它会收到这张单;「取回」= 没有人做),c 标成完成,d 再按 y 删除(无法恢复);h / Esc 到左栏。
            会话行的标题后面是它在做的单号(#9),没在做时是它最近完成的那张(✓ #8);左栏分组名后面是 完成 / 一共。
            谁等谁、接下来做哪张由这个分组的 router 决定,aca 只保存、显示和传话。命令行是 aca task(见 aca help task)
            笔记页:一条笔记两行(★ = 置顶,名字 = 它的第一行,谁写的,多久前改的;下一行是后面的内容),置顶的在前,
            其余新改的在前;右边是光标所在那一条的全文。↑↓ j k、数字、g / G 选择;e 编辑这一条,n 新写一条
            (写在右边,第一行是名字;输入时自动保存,回车换行,Esc 保存,空的不存,^G 用 $EDITOR 编辑);
            p 置顶 / 取消;d 再按 y 删除(移到回收站,^Z / b 恢复);h / Esc 到左栏。只对会话有用的键在笔记页不起作用。
            agent 用 aca note 读写的是同一本(见 aca help note)
  空格      跳转:屏上每个会话的编号换成黄色字母,按哪个字母就打开哪个;再按空格或 Esc 取消。
            字母亮着时每个分组还有一个自己的大写字母,写在左栏它的名字前面(没有左栏时写在全部分组里它的标题上;
            h 叫出来的左栏上也写):⇧ 加那个字母直接进这个分组,停在上次离开它时的那一页、那一行(一个会话都没有的分组:
            停在左栏它那一行)。分组的字母取自它的名字、照左栏的顺序分,列表里列什么都不影响;增删分组、调整顺序才可能变。
            没有分组用的大写字母只收起字母
  a         到全部分组并跳转:在分组里、在左栏上都能按,列表换成全部分组(停在上次离开时的那一行),字母同时亮起。
            字母亮着时再按 a,或者之后在全部分组里按 a:回到按 a 之前的那个分组、那一行(原来在左栏就回左栏)。
            没有可回的地方时(一直在全部分组里)a 和空格一样
  `         到左栏选分组:光标到左栏(没有左栏时叫出来盖在左边),停在列表现在所在的那一行,分组的字母同时亮起
            (和空格里 ⇧ 加的是同一个字母,这里不用 ⇧)。按哪个字母,光标就停到那个分组那一行:中间是它的会话,
            右边是和它的 router 的往来;接着按这一行的键,⏎ 进去、o 打开它的 router、s 回它一句。
            字母亮着时再按 ` 或 Esc:回到按 ` 之前的地方;按别的键字母收起,这个键照常(j k 在左栏上走)
  i         打开当前列表中下一个待处理的会话:先 ◆ 等待回应,再 ◐ 未读,同一类里最近有动静的在前(顺序同 Ctrl+Alt+N);
            看完返回后再按 i 处理下一个。已查看且没有新输出的会话会跳过
  /         搜索,高亮落在匹配的会话里最近有动静的那条(先看未停止的)

打开与查看
  ⏎         打开会话。已停止的(■)会在原处重新启动。Claude router 开新对话,其他会话继续原对话
  E         附带便签打开(桌面上的 kitty 中也可以按 Shift+Enter):见下文「便签」
  z         全屏阅读:不打开会话,只查看输出,可以向上翻看历史(↑↓ / jk 滚动、空格 / b 翻页、^D / ^U 半页、g / G 顶部 / 底部、
            J / K 切换会话、Tab 查看改动、c 复制(同列表的 c)、回车才打开会话、Esc / q / z 返回)
  x         查看改动:会话实际工作目录所在 git 仓库的 diff,顶部是文件列表。默认显示未提交的改动(包括新文件),
            按 m 切换为包含已提交的改动(与主干的分叉点对比),再按一次切回;n / p 下一个 / 上一个文件,
            e 用 $EDITOR 打开屏幕顶部那一处(定位到那一行),y 在这个仓库中打开 lazygit,返回后重新读取;
            Tab 切换到会话记录、z 切换到输出,其余按键同全屏阅读。每 2 秒自动刷新,只读(不改动 index)
  Z         会话记录(类似 Langfuse / Phoenix 的 trace):桌面上分两栏,左边是对话(每轮一块:你说的话、Claude / Codex 最后的回复、
            时间 · 耗时 · 按 API 价格折算的费用;长内容先显示开头,按 o 查看全文),右边是选中那一轮的中间过程
            (顶部是调用次数、工具数、上下文最大值;每次调用的数据、思考的第一句、中间的回复、工具改动的红绿行和输出开头)。
            → 进入右边逐步查看,o 展开 / 收起这一步
            (思考全文、带上下文和行号的改动、Read 读到的文件内容、Bash 的完整命令和输出前 200 行;▸ 表示还有未显示的内容、▾ 表示已展开,
            O 展开这一轮全部),⏎ 全屏查看这一步(token 明细、工具的输入),← / Esc 返回对话;手机上整屏显示对话,⏎ 全屏查看过程。
            代码按语言着色,改动中新增 / 删除的行铺淡绿 / 淡红底色。
            e 用 $EDITOR 以只读方式查看选中项:读写文件的工具打开那个文件本身,定位到读取 / 修改的那一行
            (vim / nvim 用 -M,无法修改或保存);其他内容(一轮、一次调用、命令和输出)写成一份 Markdown 打开,看完后删除。
            n / p 下一轮 / 上一轮,J / K 切换会话,Tab / z 查看输出,x 查看改动;运行中的会话会持续更新(停在最新一轮时)。
            启动了子代理的那一步(Claude 的 Agent、Codex 的 spawn_agent)显示子代理的数据和最后的回复,⏎ 进入后用同样的两栏查看它自己的记录,
            Esc 返回;子代理的费用计入启动它的那一轮。只读取对话记录(Claude;Codex 0.107 起,exec 会记下实际执行的命令和修改的文件);
            续接 / 分叉 / 子线程开头复制过来的几轮折叠成一行「上一段」,不计入费用;Codex 回退掉的轮次显示为灰色、不编号,费用照常计入
  t         临时终端:在界面下半屏打开一个 shell,目录是会话的实际工作目录;按键都发给它,Esc 收起(shell 继续运行,
            在同一行再按 t 回来),在里面 exit 才关闭;带上会话的账号目录(CLAUDE_CONFIG_DIR / CODEX_HOME)
  T         新窗口:在会话的 tmux 会话中新开一个窗口运行 shell(同 prefix c),并进入这个新窗口。
            新窗口是你自己的 shell:不带会话 id(在里面 aca new 不会成为它的子会话),但保留账号的配置目录
  y         在会话的实际工作目录打开 yazi(已停止的会话用记录下的目录),在 yazi 中按 q 退出后回到 aca;
            在 tmux 弹窗中,改为在原窗格旁分出一格、放大运行并切换过去,按 q 退出后这一格关闭
  c         复制,再按一个键选复制什么(底栏列出):c 最后一条回复 · b 这个会话的引用:两行,写着它是谁、在哪个目录,
            以及读它(aca output)和给它传话(aca msg)的命令,贴给另一个 agent 就能接着用 · i aca id(aca move <id> 这类
            命令使用)· s 对话 id(Claude / Codex 自己的,claude --resume 使用)· p 路径 · a 全部(实际工作目录、对话 id 和
            配置目录,贴到 aca 以外的地方用)。没有的项会注明原因,Esc 取消。手机上通过 OSC 52 复制到手机剪贴板
  前缀键 b   插入引用(同会话里的这个键):选一个会话,它的引用插到高亮那个会话的输入框,不回车;插完回到那一行。Esc 取消

  实际工作目录:Claude / Codex 自己记录的当前目录(cd 过、进入 worktree 都会跟着变);那里不是 git 仓库时,看它最近修改的
  文件所在的仓库。与登记的目录不同时,改动页顶部会注明。

新建与接管
  N         按当前配置新建:沿用选中会话的工具、账号和目录。回车创建;可以修改路径(Tab 补全,有多个候选时再按 Tab 依次切换、
            Shift-Tab 反向,/ 或 → 选定;^W 删除一级、^U 清空),↓ 或 ^F 用 fzf 模糊查找目录
            (● 有会话 ◇ 登记过的项目 ↗ zoxide 常用目录 空白 = 附近的目录;Tab 切到下一个),回车 / 双击就在那里新建;
            → 填回输入框,接着输入名字 = 在它下面新建;目录不存在时自动创建。
            分组:路径没改时用选中会话的组,改了就按路径确定(规则同 aca new -g .,见 aca help group;弹窗中会显示进入哪个组);
            工具、账号沿用选中会话;^T 切换为 shell(打开一个 shell,自己 cd、启动 claude / codex),再按一次切回
  n         新建:先选择工具和账号(可以按数字直接选),再填写目录。菜单列出 config.toml 中登记的账号
            (显示账号名,先 Claude 后 Codex;某个工具一个账号都没登记时,列出工具本身),每个账号一行:名字、工具、是否已登录、额度(列着账号的地方都是这一种行);
            然后是自定义的工具([tools.<名>],后面显示它的命令);
            ⇧↑↓ 移动当前行,shell 也可移动。顺序保存在 [ui] menu,hide 隐藏条目。
            在菜单中按 i 登录高亮的账号(已登录的先确认),a 打开账号页并停在它上面;按 + 添加账号:进入账号页,分三步 —— 先选择 Claude Code 还是 Codex,再填写名字、配置目录,
            保存到 config.toml 的 [accounts.…];目录属于另一个工具的(比如把 ~/.codex 当成 Claude 的)无法添加。
            目录是新的,就在下半屏打开终端登录(即 aca run 工具:账号 -- login;认证由工具自己完成,aca 不保存凭据)
  ^E        特殊环境:绑定了笼子或一组环境变量的账号不在 n 里,在这里单独列出,每个环境一块,标题写它在哪跑、时区和代理;
            ⏎ / 数字 用它新建,i 登录,a 账号页。在 n 里按 ^E 也会切过来,这时 Esc 回到 n(aca help config)
  ^N        新建分组:先起名(可以写「上级/名字」,空格会换成 -),回车后直接进入 fzf 选择目录(第一行是默认目录,
            即 config.toml 中 [new_group] 的 default_path,未设置时为 ~/workspace),新会话建在这个组里,这个目录记为组的默认路径
  f         分叉:带着当前对话另开一个会话,分组、账号、工具与原会话相同,挂在原会话下面。先在弹窗中填写标题(已预填「原标题 (分叉)」,
            直接回车就使用它,不锁定,之后 Claude 还能自动改名;修改过的标题会锁定,^U 清空重写);建好后立即启动,高亮跟过去。
            只适用于登记的 Claude / Codex 会话,且要有过对话才能分叉
  H         交接:另开一个会话接手它的工作。先选择新会话的工具 / 账号(同 n 的菜单,没有 shell),在原会话的目录和分组中建好,
            再把交接说明发过去:它的对话记录、整理好的文字版(双方的发言、子代理的报告、它修改过的文件,
            位于 ~/.local/state/aca/ui/handoff/)、目录、对话 id,以及它的便签;新会话读完后自行接着做,
            只有当原会话最后在向你提问、便签里又没有回答时,才会先问你。原会话不受影响;
            它仍在运行时,弹窗会提示两边会同时修改这个目录。发送失败时,说明会留在新会话的便签里(按 s 回话发出)
  X         切换账号继续(一个账号额度用完、工作还没完成时使用):不另开会话,在原处换成同一工具的另一个账号重启,
            Claude router 开新一班。其他会话复制对话记录到新账号继续。列表行、tmux 会话、标题、便签都不变。
            弹窗顶部是当前账号和额度,下面是可以切换的账号:是否已登录、额度(5h / 7d 的用量,超过 70% 显示黄色、
            超过 90% 显示红色,同计费页)。⏎ 或数字直接切换;未登录的账号无法切换,按 i 就地登录(登录后再按 X),a 账号页,+ 添加账号。
            会话正在运行 / 等待回应时,弹窗会提示切换将中断这一轮。新账号没有缓存,第一轮要把整段上下文重新写入一遍。
            因额度、登录问题停下的会话,列表那一行下面会显示原始提示和「X 换账号」。同 aca restart <id> --as 账号
  A         接管:把一个普通 tmux 会话(不是 aca 启动的:手动启动的、agent-deck 启动的)登记到 aca,无需停止它。
            先弹出确认框,写明识别出的工具、账号、对话,以及会话名将改成什么;按 y 确认接管。即 aca adopt
            (能识别什么、接管后要注意什么:aca help adopt)。接管后就可以重命名、移动分组、重启、分叉了

会话操作
  D         停止(先确认,按 y):agent 退出,窗格保留最后的画面(其中另开的窗口不受影响),登记也保留,列表中显示 ■;
            ⏎ 在原处重新启动(Claude router 开新对话,Codex 要对话过才有对话 id,没对话过的会开始新的对话)。
            在 tmux 中已不存在的(比如重启过电脑)、从归档中恢复的也照样列出,⏎ 重新创建;上一轮以出错结束的显示 ✕。
            空闲时被 aca 自动停止的显示 ☾,行上写「自动停止」,⏎ 同样会重新启动。普通会话在 config.toml 中写 [idle] stop_after = "3h",
            界面运行时每 5 分钟停止空闲超过这个时长的会话;以下情况不会停止:这一轮还没结束、有人连接着、有后台任务、输入框里有未发送的内容、
            有还没到时间的定时任务(CronCreate、/loop、aca msg --in)
            (见 aca help stop)。[idle] remove_after = "30d":停止后这么久没有动静的会话,在界面运行时像 d 一样移到回收站,
            算作一条,^Z / b 可以恢复;置顶的、有便签的不会删除
            在会话中另开的窗口 / 窗格、普通 tmux 会话上按 D:只停止这一格(程序停止,窗格保留,显示 ■),⏎ 按原来的命令在原处重新启动
  R         原地重启(Claude router 开新对话,其他会话默认继续原对话):正在运行 / 等待回应的会先确认
  r         重命名(在弹窗中修改,已预填原标题;tmux 会话名随之更改,之后不再跟随 agent 自己起的标题)。
            在分组上(标题 / 左栏那一行)按 r 修改的是分组:先改名(写「上级/名字」= 移到别的组下面,子分组、会话随之移动,
            工作区同步更新),回车后修改默认目录(已预填原来的目录,Tab 补全,清空 = 不设置;在组上按 N / t 时使用它,
            在这个目录中 aca new -g . 会进入这个组;一个目录只能作为一个组的默认目录)。同 aca group rename / dir
  m         移到分组:只更换分组,会话仍在原来的目录运行。用 fzf 选择,每行带那个组的目录(默认目录,没有设置时取组里会话的目录),
            与当前会话同目录的排在最前,其余按列表顺序;输入一个不存在的名字并回车 = 新建这个分组并移进去。
            新分组建在会话所在的分组下面,默认目录是那个分组的目录下的同名目录(没有就新建;那个分组没有目录时不设置),
            回车前写在列表上方,Tab 先修改目录再移;名字里带 / 时是从最上层起的完整路径(/名字 = 建在最上层)
  ⇧↑ ⇧↓     在组内上移 / 下移;在分组上时移动的是分组
  d         删除选中的会话,只有按 y 才删除,按其他键取消。登记的会话移到回收站(tmux 会话关闭,登记保留),1 天后才永久删除,
            在此之前可以用 ^Z / b 恢复;其中另开的窗口一并关闭(确认框会写明数量)。普通 tmux 会话 / 窗格直接 kill,无法撤销;
            普通 tmux 会话中还有别的窗口时只关闭第一个窗格,其余依次前移,只剩一个窗格时再按 d 才关闭整个会话。
            关闭前先清理其中的进程(SIGHUP + SIGTERM,两秒内未退出则 SIGKILL)。
            在分组上(标题 / 左栏那一行 / 空组)按 d 删除的是分组:确认框会写明连带删除几个会话、几个子分组,按 y 删除。
            子分组和其中的会话(包括已归档的)一起移到回收站,算作一条:^Z / b 恢复整个组,组的顺序、默认目录、工作区、笔记保持不变
  b         回收站:d 删除的内容保留 1 天,一次删除占一行(删除的分组连同其中的会话算一行),最近删除的在上。⏎ 恢复(恢复的会话处于停止状态,
            再按 ⏎ 启动),d 后按 y 立即永久删除。单独删除的笔记(笔记页的 d、aca note rm)也各占一行(✎ 名字),
            ⏎ 放回它的分组(分组已删除时一并恢复)。多选同列表(v 连选、V 连续取消、空格选中一条、Esc 先清空选择再关闭),
            ⏎ / d 对选中的几条一起操作。超过 1 天的,会在界面启动、运行期间和退出时永久删除
  ^Z        撤销上一步(可以逐步撤销,最多 10 步,退出后清空):d 删除(删除前未停止的会重新启动)/ D 停止(重新启动)/
            m 移动分组 / r 重命名 / M 挂载、卸载 MCP / p 置顶 / u 已读·未读 / Q 移到工作区 / e 便签 / 分组上的 r / v 多选后一起做的操作(一步全部撤销);
            R 重启、s 回话、f 分叉、A 接管无法撤销
  M         MCP:列出这个会话的 MCP,[ ] 表示可修改、· 表示只读。Claude 会话可以把 config.toml 中的 MCP([mcps.<名>],除 description 外,
            其余键原样就是 .mcp.json 中的一项)挂载到项目(空格切换、回车应用;写入登记目录的 .mcp.json,重启后生效)。
            挂载时把 .mcp.json 加入这个仓库本地的 .git/info/exclude(不会提交到仓库),全部卸载后删除空的 .mcp.json;
            仓库中原本就有的不改动。全局的(账号目录 .claude.json 中的)和 Codex 的(CODEX_HOME/config.toml)只列出、不修改。
            gateway 插件开启时,最上面是这个会话通过 gateway 可用的服务:空格只对这个会话关闭 / 开启,回车立即生效
            (Claude 立即切换,Codex 重启后生效);已收进 gateway 的 [mcps.<名>] 不再在「项目」中重复列出
  p         置顶 / 取消置顶。置顶的会话单独排在最上面(先置顶的在上),一天没有动静也照样列出
  u         已读 / 未读:在 ◐ 上按标为已读,在 ○ 上按标为未读;打开会话后标为已读,完成新一轮任务后变为未读。
            打开别的会话时途经刚离开的那个(为了打开后能用 ^` 回来)不算打开过
  v / V     多选,批量操作(同 yazi):v 从高亮行开始连选,用 ↑↓ j k / 数字 / J K / 点击 扩展范围,Esc 结束连选;
            V 连续取消:同样扩展一段,这一段取消选中。连选时再按 v / V:放弃还没确定的这一段,从高亮行重新开始。
            空格选中 / 取消选中一个并下移一行(在分组标题上是组里列出的那些;连选时也能按,这一段随之延长)。
            不在连选时,Esc 清空选择。
            选中的行铺绿底、行首有一道绿色标记,底栏显示选中的数量和可用的键:d 删除 / D 停止 / R 重启(先确认,
            列出是哪几个、几个运行中的会被中断;重启的会话都不在运行时不确认)· m 移动分组 · u 已读 / 未读 · p 置顶 / 取消置顶 ·
            Q+键 移到工作区。操作完成后取消选择;一起删除的在回收站中算一条,一起做的操作 ^Z 一步全部撤销。
            只能选登记的会话(窗口、子代理、普通 tmux 会话不算);被筛掉的仍保持选中。只选中一个时,效果和直接对它按键一样

  会话中另开的窗口 / 分出的窗格:d 只关闭这一格、D 只停止这一格,R / r / m 对它无效。
  普通 tmux 会话(未登记的):可以打开、查看、D / d;重命名、重启、分叉、移动分组需要先按 A 接管。

便签(写给这个会话的下一句话)
  e         写便签:写在预览的上半区(预览关闭时在弹窗中);输入时自动保存,回车换行,Esc 保存并关闭,^G 用 $EDITOR 编辑
            (在列表中直接按 ^G 也可以)。列表中显示 ✎。便签只是记下来,按回车打开会话时不会用到它。
            在分组上(标题 / 左栏那一行)按 e 写的不是便签,是给这个分组新写一条笔记(见上面 Tab 里的笔记页):
            组里有笔记时组名后面显示 ✎,置顶的笔记列在分组预览的目录下面(★ 名字);
            笔记不会填入、也不会发给任何会话,分组改名时随之保留,删除分组时一起移到回收站
  E         附带便签打开:把便签填入它的输入框、不发送,填入后删除便签,类似 Claude Code 的 stash;
            它在等待回应(◆)、已停止、不是 Claude / Codex 时不打开,并说明原因
  s         回话:不进入会话,直接回它一句。输入框和 e 在同一个位置,标题是「↩ 回话」,有便签时便签已经填在里面;
            ⏎ 发送(粘贴到它的输入框再回车,你留在列表中,运行中的会排队),^J / Shift+⏎ 换行,Esc 不发送、留作便签,^G 用 $EDITOR 编辑;
            输入时同样自动存成便签,发出后删除。按 ⏎ 时会再看一次它的状态:它正在等待回应时不发送,字留在便签里;
            会话里另开的窗口 / 窗格里是内置 agent 的(比如 agent teams 的队友),在它那一行按 s,字发进那一格;
            停着的 Claude router 用 s 发话唤醒。其他已停止的会话、非内置 agent 不打开,并说明原因。
            在等待回应(◆)的会话上是回答:列出它的问题,单选题按选项号、权限框按 y 允许 / n 拒绝(这一次),启动时的确认框按选项号;
            其余(多个问题、多选、自己写答案)按 ⏎ 进去回答。Esc / q / s 关闭,按别的键也只是关闭,不回答;问题变了会自动关闭

分组的 router(替你把这个分组的事分给合适会话的那个会话)
  @         一个分组最多一个 router,是这个分组里的一个会话。左栏它的名字前面、全部分组里它的标题上、router 自己那一行行首
            都是 @,颜色是 router 的状态。光标在这个分组的行上(左栏那一行 / 标题)时,右边是和它的往来:
            ❯ 你说的 · ● 它回的 · @ → 名字 它交给谁的话、它新建的会话 · @ ← 分组 名字 它拉过来的会话 · 名字 ❯ 别的会话发给它的;
            还没送到的写「未送达」,上次看过之后新来的是粗体,最底下一行(❯)是回它的地方。只列最近的。
            灰色 @ 表示停着。Claude router 闲满 [router] idle (默认一小时)就停。s 发话唤醒,o 或在它自己的行上按 ⏎ 也能启动。
            每一班都是新对话,第一句话是 aca 写的交接,带任务、最近往来和待送的话。规矩在角色文件里。
            它只有 aca 的分发工具和选择题工具,没有 Bash,不读项目的 CLAUDE.md 和记忆。
            Codex router 的规矩在开场话里。它空闲时不停,停着时来话暂存,启动时继续原对话。
            router 转交你这轮的请求时,aca 把原话一并捎给做活的会话。要跟进哪张单就说盯哪张。
            没盯的单,结果直接进往来。完成时只有这张单被盯着、或同组还有待交单,才会叫醒 router
  o         打开这一行所在分组的 router(没在运行的先启动):在分组的行上是这个分组的,在会话的行上是这个会话所在分组的,
            随手问那个分组(和它的会话)的是总台;按 Ctrl+Q 回来时光标还在这一行
            (界面开在 tmux 里时是直接切过去,界面随之关闭,同 ⏎)。
            还没有 router 时弹出新建框,目录照这个分组的。↑ 选 Claude 或 Codex 的工具和账号,⏎ 新建并打开「分组名 router」。
            把已有的会话设成 router、取消:aca group router(aca help group)。
            其他 tmux 会话、不在分组里的会话没有 router。别的分组的 router:` 加它的字母,再按 o
  s         在分组的行上:回它的 router 一句,写在右边最底下那一行,键同会话行上的 s(⏎ 发送,Esc 留作它的便签);
            它在等待回应(◆)时是回答框,⏎ 进它的对话。Claude router 停着时照常发送；Codex router 停着时按 o 启动
  总台      随手问那个分组(见上面「左栏」)的 router 就是总台:不知道该交给谁的事交给它,它交给合适的会话、项目的 router,
            没有就新建一个。它的 @ 在左栏「全部」那一行前面(随手问的名字前面没有)。光标在「全部」那一行、或随手问那一行上时,
            右边是和它的往来,o、s 同上。还没有总台时 o 弹出新建框:在随手问的目录里新建一个叫「总台」的会话,
            ↑ 可选工具和账号。还没设置随手问目录就先问目录。
            列表里它排在随手问的最前面(⇧↑ ⇧↓ 不移动它),随手问里不是谁的子会话的那些都画在它下面:只是画法,
            它们不是它的子会话,通知、移动、删除都和原来一样

筛选与分组
  W        进入高亮会话所在的分组(高亮还在这个会话上),在分组里再按 W 回到全部分组。换别的分组:h 到左栏
  w         列出哪些:在 未停止 和 近 7 天 之间切换。近 7 天包含未停止,顶栏写着每一档有几个(当前分组里的):

              近 7 天   上一档的全部,加上行上时间(最后有动静)不到 7 天的已停止会话

            状态可以和分组叠加,搜索时不考虑状态;不保存,下次打开时没有

作为切换器使用(tmux 弹窗)
  aca tmux install 安装后:不用前缀键,按 Ctrl+\ 打开;窗口够宽时贴在右边(宽 56 列),不够宽(手机)时全屏 —— 弹窗比窗口宽时 tmux 无法弹出;
  prefix + a 始终全屏打开;状态栏上追加一段待处理的数量(「 ◆ 2  ◐ 3」:◆ 等待回应,◐ 未读,符号同列表)。这些写在 aca 自己的一份 tmux 配置中
  (~/.config/aca/tmux.conf),你的 tmux.conf 只多一行 source-file;aca tmux uninstall 移除。想自己绑定的话,照那份配置抄
  Ctrl+Alt+N  在会话中直接按(不打开列表):打开下一个待处理的会话,先 ◆ 后 ◐;再按是下一个(aca help next)。
            由 aca 绑定,方式和 Ctrl+Q 相同;换键:aca tmux key next <键>
  前缀键 b   在会话中按 tmux 前缀键(默认 Ctrl+B)再按 b:在右侧弹出列表,⏎ 把选中会话的引用(c b 复制的那两行)插到输入框,
            不回车(aca ui --ref)。同样由 aca 绑定;换键:aca tmux key ref <键>(写 prefix b 是前缀键之后的 b)
  --client  回车只切换按键的这台客户端(手机、桌面各自切换),打开时高亮它当前所在的会话
  --follow  跟随:高亮移到哪个会话,旁边就切换到哪个,弹窗不关闭(弹窗挂在客户端上)。高亮停稳后才切换(按住方向键滑过的不切换),
            正在输入搜索词时不切换,停在分组上、不在运行的会话上时旁边不变。
            ⏎ 留在这里 · Esc 回到打开时所在的那一格 · Ctrl+\ 或 q q 关闭,留在旁边当前显示的那个会话
            经过不算查看:未读的(◐)经过之后仍是 ◐,⏎ 留下、或在它上面关闭才算查看过。
            不显示预览(旁边就是真实画面);L 照样能切换,只影响这一次,不改变手机 / 桌面各自记住的布局
  Ctrl+\    在弹窗中再按一下 = 关闭(不跟随的弹窗也一样)
  ^`        回到上一个会话(同 tmux 中的 ^`)

列表说明
  排列      按分组排列,每组前面一行是组名和组里的会话数(桌面上数写在右边、对着时间那一列;窄屏上是 ▾ 分组  数量),
            分组和组内顺序按登记表中记录的(⇧↑ ⇧↓ 调整),未分组的排在最后一个分组后面,
            普通 tmux 会话(不是 aca 创建的)在最下面;状态、活动时间变化时不改变位置。
            一个会话一行(桌面上带编号,目录、分支在预览顶部),等待回应的下面附一行它的问题。
            会话中另开的窗口 / 分出的窗格挂在它下面(├ #2 / └ #2.1,tmux 的编号),各有状态和预览;⏎ 打开后落在那一格。
            子会话(在某个会话中 aca new 的、--parent 指定的、分叉出来的)与父会话同组时挂在父会话下面(├ 标题),
            子会话自己派出的再往里缩一层(最多缩进 4 层,更深的并排显示);
            筛选时保留子会话,也保留它上面的各层;置顶一个会话时,它下面的各层也跟着置顶;删除父会话不会连带删除子会话,确认框会说明
  子代理    Claude Code / Codex 自己派出的(Claude 的 Agent 工具、Codex 的 spawn_agent)。它们运行在会话的进程中,
            没有窗格,平时不占行:会话标题后面的 +N 表示还有几个在运行。主对话已停下但后台子代理仍在运行时,这个会话显示 ●,
            不算「未读」。按 l 展开:各占一行,紧跟在会话下面、排在它的窗口前面(├ ● 类型 · 说明,灰色、不编号;
            ✓ 已完成 ✕ 出错 ■ 已停止,由其他子代理启动的带 ↳),最后一列是它运行了多久。Claude 未指定类型的
            (general-purpose)只写说明;Codex 的写「名字 · 任务名」(旧版本是 名字 · 类型 · 派活的那句话)。
            列出的是仍在运行的,加上最后一轮中启动的;会话空闲时,已完成的最多再保留半小时,更早的在 Z 中查看。
            高亮停在子代理上时:预览是根据它的记录整理的几行 —— 仍在运行的显示派给它的话、每步一行,最新的在最下面;
            已交回结果的先显示它交回的内容,从头开始(Codex 新版本派活的话是加密的,只能显示任务名)。
            ⏎ / Z 进入会话记录中它那一层,Esc 返回列表(← 返回上一层,查看是谁启动了它);它不是会话,重命名、删除、便签等键对它无效。
            只读取记录文件,和 Z 中看到的是同一份;hook 记录的路径不可用时(没带 aca 的 hook、Claude 进出 worktree
            时把记录移走了)按进程查找,没带 hook 的 Codex 无法识别对话,也就无法查看。Claude agent teams 分出的队友是真实的窗格,按窗格列出
  状态      ● 运行中(最后一列是运行时长)  ◆ 等待回应(问题或权限请求)  ◐ 未读(任务完成,尚未查看)
            ○ 空闲  ✕ 出错  ■ 已停止(agent 已退出 / D 停止 / tmux 中不存在)  ☾ 自动停止(空闲超时)
            顶栏统计当前分组、这一档(选了状态、在搜索时按它们)列出的会话。
            ✎ 有便签  ★ 置顶  ⇄ 在别处也打开着
            标题后面的 ◷ 08:57:有还没到时间的定时任务,显示最早到时间的那个,有多个时写 +N;预览中每个一行。
            Claude 的 CronCreate、/loop 的下一次只存在于它的进程中,停止、重启后就没有了;aca msg --in 的定时消息
            在收件箱里。普通会话会等它到点再自动停,Claude router 可以先停、到点再起
            登记的会话:屏幕上看得出的状态(在提问、在运行)以屏幕为准,看不出的(未读、出错)以 hook 报告的为准;其他会话只看屏幕。
            未停止 = ● ◆ ◐ ○ ✕(已停止以外的都算)
  账号      灰字,前面的 ▪ 是工具的颜色:橙色 = Claude Code、蓝色 = Codex;登记的会话显示登记的账号,
            手动启动的(shell 会话 / 普通 tmux 会话中的 claude / codex)按进程的配置目录对应到 config.toml 中的账号名,
            目录随 cd 变化
  时间      最后一列:now / 40s / 12m / 2h / 3d。登记的 Claude / Codex 不在运行时,从 hook 报告的那一刻算起
            (这一轮结束、开始等待回应、aca 启动它时):空闲时界面重绘(修改了设置、窗口大小变化)不算有动静
  预览顶部  状态、多久以前、未提交的改动(几个文件 +增 −删,没有改动时不显示)、实际工作目录、分支;有便签时接着显示便签
