aca 界面按键说明 —— 在界面里按 ? 是一屏的速查表,这里是每个键的详细说明。
进入会话后,按 Ctrl+Q(或 tmux 前缀键 + d)返回界面,会话继续运行。
Ctrl+Q 由 aca 绑定在 tmux 上,只在 aca 的会话中生效(包括其中另开的窗口 / 窗格);在普通 tmux 会话中,这个键照常发给里面的程序,
请用前缀键 + d 返回。如果你已经给 Ctrl+Q 绑定了别的操作,aca 不会覆盖。

移动与选择
  ↑↓ j k    上下移动 · g / G 到顶部、底部 · J / K 下一个、上一个分区 · 输入数字直接跳转(1 再 2 = 12 号)·
            点一下选中,再点一下进入
  滚轮      在列表上切换会话;在预览上向上翻看输出,翻到顶后按 z 全屏阅读
  h l ← →   向外 / 向里一层。h:从窗口、子代理、子会话回到所属的会话;在会话或展开的分组标题上折叠这个分组
            (高亮停在折叠行上);只看一个分组时回到全部分组(高亮不动)。l:在折叠行上展开;在分组标题上
            进入组里第一个会话。折叠只用 h,展开只用 l。
            会话派出了子代理(标题后面有 +N,或预览顶部有显示)时:l 把子代理展开成行,再按 l 进入第一个;
            h 在已展开的会话上先收起子代理,再按一次才折叠分组。没有子代理的会话上按 l 无效。
            误按也不会把列表收得只剩一组(切换分组用 { } / Tab)
  空格      跳转:编号换成黄色字母,按哪个字母就进入哪个;Esc 取消
  i         打开当前列表中最近的待处理会话(◆ 等待回应 / ◐ 未读);看完返回后再按 i 处理下一个。
            已查看且没有新输出的会话会跳过
  /         搜索

打开与查看
  ⏎         进入会话。已停止的(■)会在原处重新启动,继续原来的对话
  E         附带便签打开(桌面上的 kitty 中也可以按 Shift+Enter):见下文「便签」
  z         全屏阅读:不进入会话,只查看输出,可以向上翻看历史(↑↓ / jk 滚动、空格 / b 翻页、u / d 半页、g / G 顶部 / 底部、
            J / K 切换会话、Tab 查看改动、回车才进入会话、Esc / q / z 返回)
  x         查看改动:会话实际工作目录所在 git 仓库的 diff,顶部是文件列表。默认显示未提交的改动(包括新文件),
            按 m 切换为包含已提交的改动(与主干的分叉点对比),再按一次切回;n / p 下一个 / 上一个文件,
            e 用 $EDITOR 打开屏幕顶部那一处(定位到那一行),l 在这个仓库中打开 lazygit,返回后重新读取;
            Tab 切换到会话记录、z 切换到输出,其余按键同全屏阅读。每 2 秒自动刷新,只读(不改动 index)
  Z         会话记录(类似 Langfuse / Phoenix 的 trace):桌面上分两栏,左边是对话(每轮一块:你说的话、Claude / Codex 最后的回复、
            时间 · 耗时 · 按 API 价格折算的费用;长内容先显示开头,按 o 查看全文),右边是选中那一轮的中间过程
            (顶部是调用次数、工具数、上下文最大值;每次调用的数据、思考的第一句、中间的回复、工具改动的红绿行和输出开头)。
            → 进入右边逐步查看,o 展开 / 收起这一步
            (思考全文、带上下文和行号的改动、Read 读到的文件内容、Bash 的完整命令和输出前 200 行;▸ 表示还有未显示的内容、▾ 表示已展开,
            O 展开这一轮全部),⏎ 全屏查看这一步(token 明细、工具的输入),← / Esc 返回对话;手机上整屏显示对话,⏎ 全屏查看过程。
            代码按语言着色,改动中新增 / 删除的行铺淡绿 / 淡红底色。
            e 用 $EDITOR 以只读方式查看选中项:读写文件的工具打开那个文件本身,定位到读取 / 修改的那一行
            (vim / nvim 用 -M,无法修改或保存);其他内容(一轮、一次调用、命令和输出)写成一份 Markdown 打开,看完后删除。
            n / p 下一轮 / 上一轮,J / K 切换会话,Tab / z 查看输出,x 查看改动;运行中的会话会持续更新(停在最新一轮时)。
            启动了子代理的那一步(Claude 的 Agent、Codex 的 spawn_agent)显示子代理的数据和最后的回复,⏎ 进入后用同样的两栏查看它自己的记录,
            Esc 返回;子代理的费用计入启动它的那一轮。只读取对话记录(Claude;Codex 0.107 起,exec 会记下实际执行的命令和修改的文件);
            续接 / 分叉 / 子线程开头复制过来的几轮折叠成一行「上一段」,不计入费用;Codex 回退掉的轮次显示为灰色、不编号,费用照常计入
  t         临时终端:在界面下半屏打开一个 shell,目录是会话的实际工作目录;按键都发给它,Esc 收起(shell 继续运行,
            在同一行再按 t 回来),在里面 exit 才关闭;带上会话的账号目录(CLAUDE_CONFIG_DIR / CODEX_HOME)
  T         新窗口:在会话的 tmux 会话中新开一个窗口运行 shell(同 prefix c),并进入这个新窗口。
            新窗口是你自己的 shell:不带会话 id(在里面 aca new 不会成为它的子会话),但保留账号的配置目录
  y         在会话的实际工作目录打开 yazi(已停止的会话用记录下的目录),在 yazi 中按 q 退出后回到 aca;
            在 tmux 弹窗中,改为在原窗格旁分出一格、放大运行并切换过去,按 q 退出后这一格关闭
  c / B     复制最后一条回复 / 复制实际工作目录、对话 id 和配置目录(手机上通过 OSC 52 复制到手机剪贴板)
  C         选择要复制的内容:i aca id(aca move <id> 这类命令使用)· s session id(Claude / Codex 的对话 id,
            claude --resume 使用)· p path;也可以 ↑↓ 选择后按回车,没有的项会注明原因

  实际工作目录:Claude / Codex 自己记录的当前目录(cd 过、进入 worktree 都会跟着变);那里不是 git 仓库时,看它最近修改的
  文件所在的仓库。与登记的目录不同时,改动页顶部会注明。

新建与接管
  N         按当前配置新建:沿用选中会话的工具、账号和目录。回车创建;可以修改路径(Tab 补全,有多个候选时再按 Tab 依次切换、
            Shift-Tab 反向,/ 或 → 选定;^W 删除一级、^U 清空),↓ 或 ^F 用 fzf 模糊查找目录
            (● 有会话 ◇ 登记过的项目 ↗ zoxide 常用目录 空白 = 附近的目录;Tab 切到下一个),回车 / 双击就在那里新建;
            → 填回输入框,接着输入名字 = 在它下面新建;目录不存在时自动创建。
            分组:路径没改时用选中会话的组,改了就按路径确定(规则同 aca new -g .,见 aca help group;弹窗中会显示进入哪个组);
            工具、账号沿用选中会话;^T 切换为 shell(打开一个 shell,自己 cd、启动 claude / codex),再按一次切回
  n         新建:先选择工具和账号(可以按数字直接选),再填写目录。菜单列出 config.toml 中登记的账号
            (显示账号名,先 Claude 后 Codex;某个工具一个账号都没登记时,列出工具本身),每个账号后面显示所属工具和额度(同 X 的弹窗);
            然后是自定义的工具([tools.<名>],后面显示它的命令);
            用 [ui] 的 menu 调整顺序、hide 隐藏。最上面始终是 shell(按 1)。
            在菜单中按 + 添加账号:进入账号页(^S 的 a),分三步 —— 先选择 Claude Code 还是 Codex,再填写名字、配置目录,
            保存到 config.toml 的 [accounts.…];目录属于另一个工具的(比如把 ~/.codex 当成 Claude 的)无法添加。
            目录是新的,就在下半屏打开终端登录(即 aca run 工具:账号 -- login;认证由工具自己完成,aca 不保存凭据)
  ^N        新建分组:先起名(可以写「上级/名字」,空格会换成 -),回车后直接进入 fzf 选择目录(第一行是默认目录,
            即 config.toml 中 [new_group] 的 default_path,未设置时为 ~/workspace),新会话建在这个组里,这个目录记为组的默认路径
  f         分叉:带着当前对话另开一个会话,分组、账号、工具与原会话相同,挂在原会话下面。先在弹窗中填写标题(已预填「原标题 (分叉)」,
            直接回车就使用它,不锁定,之后 Claude 还能自动改名;修改过的标题会锁定,^U 清空重写);建好后立即启动,高亮跟过去。
            只适用于登记的 Claude / Codex 会话,且要有过对话才能分叉
  H         交接:另开一个会话接手它的工作。先选择新会话的工具 / 账号(同 n 的菜单,没有 shell),在原会话的目录和分组中建好,
            再把交接说明发过去:它的对话记录、整理好的文字版(双方的发言、子代理的报告、它修改过的文件,
            位于 ~/.local/state/aca/ui/handoff/)、目录、对话 id,以及它的便签;新会话读完后自行接着做,
            只有当原会话最后在向你提问、便签里又没有回答时,才会先问你。原会话不受影响。发送失败时,说明会留在新会话的便签里(按 s 发送)
  X         切换账号继续(一个账号额度用完、工作还没完成时使用):不另开会话,在原处换成同一工具的另一个账号重启,
            继续这段对话 —— 对话记录复制到新账号的配置目录,上下文完整保留,列表行、tmux 会话、标题、便签都不变。
            弹窗顶部是当前账号和额度,下面是可以切换的账号:是否已登录、额度(5h / 7d 的用量,超过 70% 显示黄色、
            超过 90% 显示红色,同计费页)。⏎ 或数字直接切换;未登录的账号无法切换,按 a 去账号页登录、+ 添加账号(登录后再按 X)。
            会话正在运行 / 等待回应时,弹窗会提示切换将中断这一轮。新账号没有缓存,第一轮要把整段上下文重新写入一遍。
            因额度、登录问题停下的会话,列表那一行下面会显示原始提示和「X 换账号」。同 aca restart <id> --as 账号
  A         接管:把一个普通 tmux 会话(不是 aca 启动的:手动启动的、agent-deck 启动的)登记到 aca,无需停止它。
            先弹出确认框,写明识别出的工具、账号、对话,以及会话名将改成什么;按 y 确认接管。即 aca adopt
            (能识别什么、接管后要注意什么:aca help adopt)。接管后就可以重命名、移动分组、重启、分叉了

会话操作
  D         停止(先确认,按 y):agent 退出,窗格保留最后的画面(其中另开的窗口不受影响),登记也保留,列表中显示 ■;
            ⏎ 在原处重新启动,继续原来的对话(Codex 要对话过才有对话 id,没对话过的会开始新的对话)。
            在 tmux 中已不存在的(比如重启过电脑)、从归档中恢复的也照样列出,⏎ 重新创建;上一轮以出错结束的显示 ✕。
            空闲时被 aca 自动停止的显示 ☾,行上写「自动停止」,⏎ 同样会重新启动并继续对话:在 config.toml 中写 [idle] stop_after = "3h",
            界面运行时每 5 分钟停止空闲超过这个时长的会话;以下情况不会停止:这一轮还没结束、有人连接着、有后台任务、输入框里有未发送的内容、
            有还没到时间的定时任务(CronCreate、/loop、aca msg --in)
            (见 aca help stop)。[idle] remove_after = "30d":停止后这么久没有动静的会话,在界面运行时像 d 一样移到回收站,
            算作一条,^Z / b 可以恢复;置顶的、有便签的不会删除
            在会话中另开的窗口 / 窗格、普通 tmux 会话上按 D:只停止这一格(程序停止,窗格保留,显示 ■),⏎ 按原来的命令在原处重新启动
  R         重启(在原处重启,继续原来的对话,其他窗口不受影响):正在运行 / 等待回应的会先确认
  r         重命名(在弹窗中修改,已预填原标题;tmux 会话名随之更改,之后不再跟随 agent 自己起的标题)。
            在分组上(标题 / 折叠行)按 r 修改的是分组:先改名(写「上级/名字」= 移到别的组下面,子分组、会话随之移动,
            工作区、折叠状态同步更新),回车后修改默认目录(已预填原来的目录,Tab 补全,清空 = 不设置;在组上按 N / t 时使用它,
            在这个目录中 aca new -g . 会进入这个组;一个目录只能作为一个组的默认目录)。同 aca group rename / dir
  m         移到分组:只更换分组,会话仍在原来的目录运行。用 fzf 选择,每行带那个组的目录(默认目录,没有设置时取组里会话的目录),
            与当前会话同目录的排在最前,其余按列表顺序;输入一个不存在的名字并回车 = 新建这个分组并移进去
  ⇧↑ ⇧↓     在组内上移 / 下移;在分组上时移动的是分组
  d         删除选中的会话,只有按 y 才删除,按其他键取消。登记的会话移到回收站(tmux 会话关闭,登记保留),1 天后才永久删除,
            在此之前可以用 ^Z / b 恢复;其中另开的窗口一并关闭(确认框会写明数量)。普通 tmux 会话 / 窗格直接 kill,无法撤销;
            普通 tmux 会话中还有别的窗口时只关闭第一个窗格,其余依次前移,只剩一个窗格时再按 d 才关闭整个会话。
            关闭前先清理其中的进程(SIGHUP + SIGTERM,两秒内未退出则 SIGKILL)。
            在分组上(标题 / 折叠行 / 空组)按 d 删除的是分组:确认框会写明连带删除几个会话、几个子分组,按 y 删除。
            子分组和其中的会话(包括已归档的)一起移到回收站,算作一条:^Z / b 恢复整个组,组的顺序、默认目录、工作区、便签保持不变
  b         回收站:d 删除的内容保留 1 天,一次删除占一行(删除的分组连同其中的会话算一行),最近删除的在上。⏎ 恢复(恢复的会话处于停止状态,
            再按 ⏎ 继续原来的对话),d 后按 y 立即永久删除。多选同列表(v 连选、V 连续取消、空格选中一条、Esc 先清空选择再关闭),
            ⏎ / d 对选中的几条一起操作。超过 1 天的,会在界面启动、运行期间和退出时永久删除
  ^Z        撤销上一步(可以逐步撤销,最多 10 步,退出后清空):d 删除(删除前未停止的会重新启动)/ D 停止(重新启动,继续原来的对话)/
            m 移动分组 / r 重命名 / M 挂载、卸载 MCP / p 置顶 / u 已读·未读 / Q 移到工作区 / e 便签 / 分组上的 r / v 多选后一起做的操作(一步全部撤销);
            R 重启、s 发送、f 分叉、A 接管无法撤销
  M         MCP:列出这个会话的 MCP,[ ] 表示可修改、· 表示只读。Claude 会话可以把 config.toml 中的 MCP([mcps.<名>],除 description 外,
            其余键原样就是 .mcp.json 中的一项)挂载到项目(空格切换、回车应用;写入登记目录的 .mcp.json,重启后生效)。
            挂载时把 .mcp.json 加入这个仓库本地的 .git/info/exclude(不会提交到仓库),全部卸载后删除空的 .mcp.json;
            仓库中原本就有的不改动。全局的(账号目录 .claude.json 中的)和 Codex 的(CODEX_HOME/config.toml)只列出、不修改。
            gateway 插件开启时,最上面是这个会话通过 gateway 可用的服务:空格只对这个会话关闭 / 开启,回车立即生效
            (Claude 立即切换,Codex 重启后生效);已收进 gateway 的 [mcps.<名>] 不再在「项目」中重复列出
  p         置顶 / 取消置顶。置顶的会话单独排在最上面(先置顶的在上),一天没有动静也照样列出
  u         已读 / 未读:在 ◐ 上按标为已读,在 ○ 上按标为未读;进入会话后标为已读,完成新一轮任务后变为未读。
            进入别的会话时途经刚离开的那个(为了进去后能用 ^` 回来)不算进入过
  v / V     多选,批量操作(同 yazi):v 从高亮行开始连选,用 ↑↓ j k / 数字 / J K / 点击 扩展范围,Esc 确定;
            V 连续取消:同样扩展一段,这一段取消选中。连选时再按 v / V:放弃还没确定的这一段,从高亮行重新开始。
            空格选中 / 取消选中一个并下移一行(在分组标题上是组里列出的那些;连选时也能按,这一段随之延长)。
            不在连选时,Esc 清空选择。
            选中的行铺绿底、行首有一道绿色标记,底栏显示选中的数量和可用的键:d 删除 / D 停止 / R 重启(先确认,
            列出是哪几个、几个运行中的会被中断;重启的会话都不在运行时不确认)· m 移动分组 · u 已读 / 未读 · p 置顶 / 取消置顶 ·
            Q+键 移到工作区。操作完成后取消选择;一起删除的在回收站中算一条,一起做的操作 ^Z 一步全部撤销。
            只能选登记的会话(窗口、子代理、普通 tmux 会话、折叠行不算);被筛掉、被折叠的仍保持选中。只选中一个时,效果和直接对它按键一样

  会话中另开的窗口 / 分出的窗格:d 只关闭这一格、D 只停止这一格,R / r / m 对它无效。
  普通 tmux 会话(未登记的):可以进入、查看、D / d;重命名、重启、分叉、移动分组需要先按 A 接管。

便签(写给这个会话的下一句话)
  e         写便签:写在预览的上半区(预览关闭时在弹窗中);输入时自动保存,回车换行,Esc 保存并关闭,^G 用 $EDITOR 编辑
            (在列表中直接按 ^G 也可以)。列表中显示 ✎。便签只是记下来,按回车进入会话时不会用到它。
            在分组上(标题 / 折叠行)写的是这个组的便签:记录整体的想法,组名后面显示 ✎,预览中写在目录下面;
            不会填入、也不会发给任何会话,分组改名时随之保留,删除分组时一起移到回收站

  账号      橙色 = Claude Code、蓝色 = Codex;登记的会话显示登记的账号,手动启动的(shell 会话 / 普通 tmux 会话中的
            claude / codex)按进程的配置目录对应到 config.toml 中的账号名,目录随 cd 变化
  时间      最后一列:now / 40s / 12m / 2h / 3d。登记的 Claude / Codex 不在运行时,从 hook 报告的那一刻算起
            (这一轮结束、开始等待回应、aca 启动它时):空闲时界面重绘(修改了设置、窗口大小变化)不算有动静
  预览顶部  状态、多久以前、未提交的改动(几个文件 +增 −删,没有改动时不显示)、实际工作目录、分支;有便签时接着显示便签

保存位置、配色和语言
  分组、范围(和天数)、布局(桌面、手机各一份)、高亮的会话、折叠状态:下次打开时恢复(带关键词打开时不恢复)。
  都在 ~/.local/state/aca/ui/ 下:view(视图)、pinned(置顶)、read(已读)、spaces(工作区)、notes(便签),手机和桌面共用。

  界面语言:默认英文;在 ^S 设置中按 l 在 zh / en 之间立即切换(记入 config.toml 的 [ui] lang),也可以用环境变量 ACA_LANG=zh。
