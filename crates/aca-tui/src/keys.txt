aca 界面里的键 —— 界面里按 ? 是一屏的速查表,这里是每个键的细节。
进去之后:Ctrl+Q(或 tmux 前缀键 + d)回到界面,会话照样跑。
Ctrl+Q 是 aca 绑在 tmux 上的,只在 aca 的会话里算数(连同里面另开的窗口 / 窗格);普通 tmux 会话里这个键照样送给里面的程序,
回来用前缀键 + d。你自己给 Ctrl+Q 绑了别的,aca 不动它。

列表怎么读
  排列      按分组分区(▾ 分组  几个),分组和组内顺序取登记表里记的(⇧↑ ⇧↓ 挪),没分组的在最后一个分组后面,
            普通 tmux 会话(不是 aca 建的)在最下面一区;状态、活动时间变了不挪位置。
            一个会话一行(桌面上带编号,目录、分支看预览头),在等你选的下面挂一行它问的。
            会话里另开的窗口 / 分出来的窗格挂在它下面(├ #2 / └ #2.1,tmux 的编号),各有状态和预览;⏎ 进去落在那一格。
            子会话(在某个会话里 aca new 的、--parent 指定的、分叉出来的)同组时挂在父会话下面(├ 标题),
            子会话自己派出去的再往里一层(最多缩 4 层,更深的并排着画);
            筛选时子会话留下,它上面各层也留下;置顶一个会话,它下面各层跟着上去;删父会话不连带子会话,确认框会说
  子代理    Claude Code / Codex 自己派出去的(Claude 的 Agent 工具、Codex 的 spawn_agent)。它们跑在会话的进程里,
            没有窗格,平时不占行:会话标题后面的 +N 是还有几个在跑。主对话停了、后台的子代理还在跑,这个会话算 ●,
            不算「跑完没看」。l 展开:各占一行,紧跟在会话下面、排在它的窗口前面(├ ● 类型 · 说明,灰字、不编号;
            ✓ 跑完了 ✕ 出错 ■ 被停了,别的子代理再起的带 ↳),最后一列是它跑了多久。Claude 没指定类型的
            (general-purpose)只写说明;Codex 的写「名字 · 任务名」(老版本是 名字 · 类型 · 派活那句话)。
            列的是还在跑的,加上最后一轮里起的;会话空着时跑完的最多再留半小时,更早的在 Z 里看。
            高亮停在上面:预览是它的记录写成的几行 —— 还在跑的是派给它的话、一步一行,最新的在最下面;
            交回话了的先写它交回来的话,从头看(Codex 新版本派活的话是加密的,只写得出任务名)。
            ⏎ / Z 进会话记录里它那一层,Esc 回列表(← 往上一层,看是谁起的它);它不是会话,改名、删除、便签这些键不对它。
            只读记录文件,和 Z 里看到的是同一份;hook 记的记录路径用不了时(没带 aca 的 hook、Claude 进出 worktree
            把记录挪走了)按进程去找,Codex 没带 hook 的认不出对话,看不了。Claude 的 agent teams 分出来的队友是真的窗格,照窗格列
  状态      ● 在跑(最后一列是已跑多久)  ◐ 在等你:红 = 选择框 / 确认框,黄 = 跑完了还没看
            ○ 空闲  ✕ 出错  ■ 没在跑(agent 退出了 / D 停掉的 / tmux 里没有的)  ✎ 有便签  ★ 置顶  ⇄ 别处也打开着
            登记的会话:屏幕上看得出的(在问、在跑)以屏幕为准,看不出的(跑完没看、出错)听 hook 报的;别的只看屏幕。
            开着的 = ● ◐ ○ ✕(没在跑的以外都算),不管多久以前
  账号      橙色 = Claude Code、蓝色 = Codex;登记的会话写登记的账号,手动起的(shell 会话 / 普通 tmux 会话里的
            claude / codex)按它进程的配置目录对回 config.toml 里的账号名,目录跟着 cd 走
  时间      最后一列:now / 40s / 12m / 2h / 3d
  预览顶上  状态、多久以前、未提交的改动(几个文件 +加 −删,干净的写「没改动」)、真正干活的目录、分支;有便签时接着是便签
