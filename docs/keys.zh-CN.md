# 按键

[English](keys.md) | 简体中文

界面的按键:在列表里、在会话里面,以及在任何 tmux 会话里。

在界面里每一页按 `?` 都能看到这一页的键:在里面按某个键,就是在这一页按它。`aca help keys` 有每个键的详细说明。

**在列表里**

| 按键 | 作用 |
|---|---|
| `↑` `↓` 或 `j` `k` | 上下移动;按数字直接选中对应编号的会话 |
| `回车` | 进入会话。已停止的(`■`)会先启动。Claude router 会开一段新对话 |
| `n` / `N` | 新建 / 按当前配置新建(沿用工具、账号和目录) |
| `i` | 打开下一个待处理的会话(`◆` 等待回应或 `◐` 未读) |
| `空格` | 屏上每个会话显示一个字母,按对应的字母直接进入。每个分组在左栏上还有一个自己的大写字母:`Shift` 加它直接进那个分组。再按 `空格` 取消 |
| `a` | 在分组里按:回到全部分组,同时显示这些字母。再按 `a` 回到刚才的位置 |
| `` ` `` | 光标到左栏(窄屏上叫出来盖在左边),每个分组显示一个字母:按哪个,光标就停到那个分组那一行,右边是和它的 router 的往来。接着 `回车` 进去、`o` 打开它的 router、`s` 回它一句。再按 `` ` `` 回到原处 |
| `/` | 过滤列表 |
| `z` | 全屏查看输出,不进入会话 |
| `x` | 查看改动:会话工作目录的 git diff |
| `Z` | 按轮次查看对话记录:执行了什么、改了什么、每一轮的花费 |
| `e` | 写便签,即准备对它说的下一句话(在分组上是给这个分组新写一条笔记;`Esc` 保存) |
| `s` | 回话:不进入会话,直接回它一句。写在 `e` 的位置(有便签时已经填在里面),`Enter` 发送,`Ctrl+J` 换行,`Esc` 留作便签。在 `◆` 的会话上是回答:按选项号,权限框按 `y` / `n` |
| `f` | 分叉:新建一个会话,从当前对话继续 |
| `H` | 交接:新建一个会话(工具、账号可另选),接手它的工作 |
| `X` | 切换账号,用于当前账号额度用完时。Claude router 在新账号上开新一班 |
| `r` / `R` / `D` | 重命名 / 重启 / 停止 |
| `d` | 删除:在分组上会连同其中的会话一起删除。删除的内容在回收站保留 1 天,`Ctrl+Z` 撤销 |
| `b` | 回收站:删除的会话、分组、笔记保留 1 天,`⏎` 恢复;`v` 多选,批量恢复或永久删除 |
| `m` / `p` | 移到分组 / 置顶 |
| `v` `V` | 多选(同 yazi):`v` 后上下移动选中一段(`Esc` 结束),`V` 同样移动但取消选中,`空格` 选中或取消一个;之后按 `d` `D` `R` `m` `u` `p` `Q` 对所有选中的会话执行,`Ctrl+Z` 一步撤销 |
| `h` | 光标到左栏:只看某个分组,或查看全部(屏幕不到 130 列时叫出来盖在左边) |
| `o` | 在分组的行上:打开这个分组的 router(把这个分组的事分给合适会话的那个会话;名字前面有 `@`),还没有就新建一个。右边是和它的往来,`s` 在这里回它一句。左栏「全部」那一行上:打开总台(随手问那个分组的 router,替你把不知道该给谁的事交出去),`s` 同样是回它。在会话的行上、分组的任务页和笔记页上:打开这个分组的 router(别的分组的:`` ` `` 加它的字母,再按 `o`) |
| `Tab` | 在一个分组里:换到它的下一页,任务 / 会话 / 笔记。任务页上 `⏎` 打开做这张单的会话,`s` 回它,`n` 新任务,`e` 修改,`m` 交给一个会话,`c` 完成,`d` 删除;命令行是 `aca task`。笔记页上 `e` 编辑光标所在的那一条,`n` 新写一条,`p` 置顶,`d` 删除;agent 用 `aca note` 读写的是同一本 |
| `$` | 用量和花费 |
| `P` | 插件页 |
| `?` | 这一页的键和作用;在列表上,插件的命令排最前面。按哪个就执行哪个,`/` 筛选 |
| `Ctrl+S` | 设置主题、语言、账号和登录。`c` 开关所有已安装的外部渠道，缺的设置回列表按 `P` 填 |
| `Ctrl+L` | 原地重启界面,例如安装新版本之后 |
| `q` `q` | 退出 aca,会话继续运行。在 tmux 弹窗里按 `Esc` 也能关闭 |

灰色 `@` 表示 router 停着。在分组行上按 `s` 发话可以叫醒 Claude router,`o` 打开它。
闲满 `[router] idle`(默认一小时)就会停,每次启动都开新对话,第一句话是 aca 写的交接。
规矩在角色文件里,它只用 aca 的分发工具和选择题工具,没有 Bash,不读项目的 CLAUDE.md 和记忆。
Codex router 的规矩仍在开场话里。它空闲时不停,停着时来话暂存,按 `o` 启动后继续原对话。

router 交代工作时,aca 把你的原话捎给做活的会话。想跟进哪张单就说盯哪张。没盯的单,结果直接进往来。
完成时只有这张单被盯着、或同组还有待交单,才会叫醒 router。

**在会话里面**

| 按键 | 作用 |
|---|---|
| `Ctrl+Q` | 回到列表,agent 继续运行 |
| `Ctrl+Alt+N` | 直接进入下一个待处理的会话 |
| 前缀键,再按 `b` | 选一个会话,把它的引用(`c` `b` 复制的那两行)插到输入框,不回车。在列表里按也行:插到高亮的那个会话 |

这几个键只在 aca 启动的会话里有效,在其他地方会照常传给里面的程序(前缀键 + `b` 在其他地方什么也不做)。在其他 tmux 会话里,用 tmux 前缀键加 `d` 返回。

**在任何 tmux 会话里,运行过 `aca tmux install` 之后**(可选,见[可选的工具](install.zh-CN.md#可选的工具))

| 按键 | 作用 |
|---|---|
| `Ctrl+\` | 在右侧打开 aca 作为切换器;高亮移到哪个会话,旁边就切换到哪个 |
| 前缀键,再按 `a` | 全屏打开 aca |

**改键。** 界面里的键是固定的,不能改。下面这些可以改:

- `Ctrl+Alt+N`:`aca tmux key next <键>`,键名用 tmux 的写法,比如 `M-n`、`F7`。它记在 `config.toml` 的
  `[keys] next` 里,设为 `""` 表示不绑定。
- 前缀键 + `b`:`aca tmux key ref <键>`,记在 `[keys] ref`;写 `prefix b` 表示前缀键之后的 `b`,也可以换成不带前缀的键。
  默认不用 Ctrl+Alt 加字母:窗口管理工具(比如 Rectangle)常把 Ctrl+Option 组合当快捷键,键到不了 tmux。
- `Ctrl+\` 和前缀键 + `a` 写在 `~/.config/aca/tmux.conf` 里,升级 aca 时这份文件会被重写。想换成别的键,
  在你自己的 `tmux.conf` 里、加载这份文件的那一行后面 unbind / bind。
- `Ctrl+Q`:如果你自己在 tmux 里绑定过它,aca 不会修改你的设置;这时用前缀键 + `d` 返回。
- 插件的键(列表的 `?` 里的和会话里面的):在插件页(`P`)里改,或者用 `aca plugin hotkey`。见
  [docs/plugins.zh-CN.md](plugins.zh-CN.md)。
